## 1. 这是什么

A 股股权激励股票池（196 只）的**纯技术面复盘诊断画像**模块：6 个开源方法学引擎
（Volume Profile / SMC / 缠论背离 / 经典形态 / Wyckoff / 道氏）并行出信号，
经防未来函数闸门（walk-forward 多切点对拍）体检后，做四维共振投票与六维评分卡，
输出 HTML + JSON + Excel 三件套。**不含任何交易回测、不给买卖建议。**

## 4. 已知边界与遗留问题（如实告知）

1. **state 类信号不参与对拍**（设计使然）：筹码位置/阶段判定天然依附最后一根 K 线，
   任何切点下都落在末尾，比了必误报。代价是：若引擎把未来函数藏进 state 信号，
   闸门抓不到。缓解：共振时效票只消费 event 信号。这是本轮评审最希望专家挑战的点。
2. **`identity()` 指纹碰撞**：同引擎/同类型/同方向/同形成日的两条信号会被对拍字典
   合并（后者覆盖前者），理论上可能掩盖差异。当前 6 引擎实际输出未观察到碰撞，风险低。
3. **196/196 通过不等于算法正确**：体检只证明"不偷看未来 + 时序合法"，
   不证明信号本身有预测力。请勿把体检通过率读成策略有效性。
4. **性能**：每引擎体检需 6~7 次全量重算，全池 E2E 约分钟级，未做增量优化。
5. **许可证**：仓库暂未选择开源许可证（保留所有权利）。若要对外协作/引用，
   请先与作者确认许可证选择——**勿默认视为可自由使用**。

## 5. 评审史摘要

  跨年缺口算法、一字板条件恒假、引擎 `[-N:]` 截尾破坏对拍等 2×P0 + 6×P1。
- Round 7（交付核验）：复核 guard 新发现并已修复——
  - **D1**：历史 `--as-of` 下"确认日晚于基准日"被误报（全量结果错套 as_of 上界）；
  - **D2**：`STATE_RANK` confirmed/invalidated 同级，"失效复活"型重绘漏检。
  - 两项均有修复前失败、修复后通过的最小复现测试。
- 测试规模：29 条（干净环境 28 passed + 1 skipped； skipped 为需行情缓存的集成测试）。
